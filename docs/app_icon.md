# App icon

The borderless Saint Jean to Santiago artwork is retained at `assets/branding/app_icon.png`. Android launcher PNGs, iOS and macOS app icon catalogs, and the Windows ICO are generated from the complete artwork, with artwork extending to every edge. iOS icons are opaque RGB images. No runtime dependency is added.

Rebuild and reinstall to see the icon. Existing installed builds do not change automatically. Native device/store validation remains to be performed.
