# Stage detail

The summary uses published stage distance and the existing AheadOfMeService incoming track weights, normalized by WalkingTime to the saved flat-ground pace. Missing/incomplete tracks show unavailable estimates. The places timeline uses path-destination cumulative distances, never straight-line distances. Only confirmed-present services are shown.

Start navigation opens the existing route screen; it does not automatically enable background alerts. Stages without full guidance show View route map. Add to my plan preselects both stage endpoints in the existing editable planning form and still requires the user to save. Existing location-page planning behavior is unchanged.

Published map and elevation sections expand on demand, retaining hotspot links and access to the interactive elevation profile. They remain above detailed route guidance. Alternative and next-stage links display stored names, with ID fallback while loading. SafeArea protects content from system navigation controls.
